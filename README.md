A one-star review of Monday, written as if Monday were a restaurant — for the
[One Star for Monday](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61)
bounty on make.fun.

`main.py` writes the review to `/output/entry.txt`:

> One star: I asked for a fresh week and got Sunday's leftovers, cold. The waiter — my alarm — never even showed up.

Run it with `python3 main.py`.
